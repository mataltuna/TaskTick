# TaskTick ✅

TaskTick is a modern, frontend-only web application designed for efficient task management. It features a clean, responsive user interface and simulates user authentication and database fetching using Vanilla JavaScript.

## 🚀 Live Demo
[Click here to view the live project](https://mataltuna.github.io/TaskTick/) *(Asegurate de que este link sea el correcto)*

## 🛠️ Features
- **User Authentication:** Simulated login system verifying user data against a local JSON database.
- **Task Management:** Users can add, complete, and delete tasks dynamically.
- **Modern UI/UX:** 
  - Responsive grid layout adapting to different screen sizes.
  - Custom violet-pastel color palette with hover and active states.
  - Smooth auto-scrolling to newly created tasks.
  - Custom CSS scrollbars for long text descriptions.
- **Data Persistence:** Tasks and login states are saved using the browser's `localStorage`.

## 💻 Technologies Used
- **HTML5:** Semantic structure.
- **CSS3:** Native CSS Variables, Flexbox, and CSS Grid.
- **JavaScript (Vanilla):** DOM Manipulation, Fetch API, Async/Await, and LocalStorage.
- **SweetAlert2:** For modern and interactive alert modals.
